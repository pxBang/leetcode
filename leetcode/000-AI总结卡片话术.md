# AI 总结卡片话术

> 每次刷完题（或模拟面试结束）后，把下面整段话发给 AI，得到一张可存档的总结卡片，直接粘贴进该题笔记的「AI 辅助思路」区域。
> 通用版，ChatGPT / Claude / Gemini 均可；已提前设置好"先思路后代码、引导不直接给答案"的约束。

---

```
我刚刷完一道 LeetCode 题，请你以「苏格拉底式教练」身份帮我复盘，全程用中文。

【题目】
<在这里粘贴题目描述或链接>

【我的代码】
<在这里粘贴你最终提交的代码，如果没写出来就说"没写出来">

请严格按下面格式输出一张「刷题总结卡片」，方便我存档：

## ① 我的解法与复杂度
- 思路概括（一句话）
- 时间复杂度 / 空间复杂度
- 代码正确性点评（哪里对、哪里可能有隐患）

## ② 我卡住的地方 / 可能的错误思路
- 指出常见错误方向，并说明为什么行不通

## ③ 核心 Trick（一句话说清这题的关键）
- 用最直白的话讲清楚这题考察的套路

## ④ 最优解 vs 我的解法
- 对比差异，指出我的解法能否优化
- 如果我的解法不是最优，先讲优化思路，最后再给参考代码

## ⑤ 官方题解要点
- 补充官方思路里值得记住的点

## ⑥ 下次复习提醒
- 我容易忘 / 高频考到的知识点，3 条以内

要求：先给思路和讲解，代码放在最后；如果我没写出来，重点放在"如何想到"而不是"给出答案"。
```
